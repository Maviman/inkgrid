Inkgrid
=======

Start it from the Start Menu (or the desktop shortcut). It opens in its own window and works offline.
Nothing is uploaded anywhere: pictures and videos stay on this PC.

Your settings live in %LOCALAPPDATA%\Inkgrid. Uninstalling asks before deleting them.

Home-network server (if you installed it): Start Menu > "Inkgrid network server". It prints the
address to open on your phone or another PC. Allow Node.js on Private networks when Windows Firewall asks.
There is no login, so anyone on your network can open it while that window is running.

Updating: run a newer Inkgrid-Setup.exe. It upgrades in place and keeps your settings.
Uninstall: Settings > Apps > Installed apps > Inkgrid.
