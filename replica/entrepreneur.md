# Entrepreneur pass (mostly N/A)

This is a private, single-user tool with no market, so the review mining, ranking and positioning steps were skipped on purpose. No reviews were scraped.

What was carried over is the "fix what's annoying in the original" part, from the recon itself:

| friction in the original | what the clone does |
| --- | --- |
| Export needs an account sign-up | No accounts; one passphrase at the edge, then export is one click |
| No plain-text output | Copy text (clipboard, .txt fallback) for every character style |
| Still pictures can't export video unless you know about Animate | Save video dialog says why it's disabled and how to enable it |
| Big uploads | Sources over 4096px are scaled down on load instead of choking the renderer |
