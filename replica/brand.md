# Brand

- **Name: Inkgrid.** Short, says what it does (ink on a grid). Private tool, so trademark, store and handle checks are N/A; if it ever goes public, run a USPTO/EUIPO search and check the domain first.
- **Palette:** graphite neutrals with a phosphor-mint accent (#5fe3a1). The original uses near-black with a cool white. All text pairs pass WCAG AA (replica/design/tokens.json, contrast.py: 12 pairs, 0 failures).
- **Logo:** a rounded square with three rows of dashes in the accent colour (index.html, public/favicon.svg). Drawn here, no traced assets.
- **Type:** JetBrains Mono (SIL OFL, bundled under public/fonts with its licence) plus system UI.
- **Voice:** short, plain labels (Open file, Demo scene, Save image, Split view). All copy, preset names and hints written fresh.
- **Sweep:** `sweep.py . --config replica/sweep.json` is clean: no original name, domain, colours or preset names remain.
